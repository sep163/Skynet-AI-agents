## Ограничения

- Данные демо: телеметрия из симулятора, тарифы и адреса выдуманы. На пилоте — адаптеры к системам SkyNet.
- Сценариев проверки мало: это проверка работоспособности, а не статистика.
- Персональные данные и зарубежная модель: нужна проверка по 152-ФЗ; можно переключить на GigaChat, YandexGPT или локальную модель.
- Безопасность пилота: вход клиента через подписанный токен личного кабинета, авторизация во внутреннем интерфейсе, `WIDGET_ORIGINS` вместо `*`.
